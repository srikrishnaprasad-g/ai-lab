# ADR Lifecycle

Each ADR follows the lifecycle below.

- Draft
- Review
- Accepted
- Deprecated
- Archived

---

# Creating New ADRs

A new ADR should be created when:

- Introducing a major technology.
- Changing architectural direction.
- Adopting new engineering standards.
- Making significant repository changes.

Minor implementation decisions should not require ADRs.
