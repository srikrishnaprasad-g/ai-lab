# Request Lifecycle

1. User submits a query.

↓

2. Frontend validates input.

↓

3. FastAPI receives request.

↓

4. ResearchService validates business rules.

↓

5. ResearchEngine orchestrates workflow.

↓

6. AI Runtime coordinates agents.

↓

7. Providers execute LLM requests.

↓

8. Runtime aggregates results.

↓

9. Engine formats response.

↓

10. API returns structured JSON.

↓

11. Frontend renders report.
