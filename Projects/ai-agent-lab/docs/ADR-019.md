# ADR-019: Explicit System Prompt Transmission

Status: Accepted

Problem:
The Gemini Provider was previously sending the system instructions as part of the user prompt, violating the architectural intent of separating system-level directives from user-task instructions. This also caused poor LLM instruction compliance.

Context:
- `PromptResult` has both `prompt` and `system_prompt` fields.
- The Gemini REST API supports `systemInstruction`.

Chosen Solution:
- Explicitly map `LLMRequest.system_prompt` to `systemInstruction` in `GeminiProvider`.
- Maintain clean separation between the user prompt (task) and the system prompt (instruction) in `SummaryPromptBuilder`.
- Use `PromptResult` fields correctly in `SummaryAgent`.

Consequences:
- Better adherence to the provider-agnostic architectural principle.
- Improved LLM JSON output quality due to superior instruction delivery.
- Slightly higher complexity in `GeminiProvider` to handle conditional `systemInstruction`.
