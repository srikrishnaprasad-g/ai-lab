All notable changes to Executive Research are documented in this file.

# v1.0.0

**Release Date:** August 2026

## Added

- Public web application
- FastAPI backend
- Next.js frontend
- AI Agent Lab runtime integration
- Tavily web search integration
- Gemini-based executive summarization
- PDF report generation
- Downloadable PDF reports
- Public Render deployment
- Public Vercel deployment

## Changed

- Migrated from command-line execution to browser-based experience.
- Replaced local-only workflow with cloud deployment.
- Integrated frontend with existing AI Agent Lab runtime.
- Eliminated duplicate orchestration logic introduced during earlier web integration experiments.

## Fixed

- Runtime integration issues
- PDF download workflow
- Frontend API configuration
- Backend deployment configuration
- Render import path issues
- CORS configuration
- Production deployment issues
- TypeScript production build errors
