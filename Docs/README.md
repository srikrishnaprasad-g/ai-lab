# AI Product Engineering Lab

## Overview

This repository contains my personal AI engineering workspace for learning, experimenting, and building AI-powered product management workflows.

The environment is centered around Claude Code while using Google Gemini as the underlying LLM through Claude Code Router.

---

## Architecture

```
Claude Code
        │
        ▼
Claude Code Router
        │
        ▼
Google AI Studio (Gemini 2.5 Flash)
```

OpenRouter is configured as a secondary provider for future experimentation.

---

## Objectives

- Learn Claude Code
- Learn AI-assisted software engineering
- Build AI agents
- Build Product Management copilots
- Create reusable prompts
- Learn MCP servers
- Automate Product Management workflows
